# ICT Conscript Admission Test
Project is deployed at https://akaseli.github.io/test-ictconscript-admission/

This is a simple logbook created in a few hours following the requirements of task [01a-swdev-frontend](https://github.com/Akaseli/test-ictconscript-admission/blob/main/challenges/01a-swdev-frontend.MD).

## Running locally
1. Clone repository
```
git clone https://github.com/Akaseli/test-ictconscript-admission.git
cd test-ictconscript-admission
```
2. Install dependencies and run the project locally
```
npm install
npm run dev
```
